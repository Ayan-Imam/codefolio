# CodeFolio

A no-code / low-code portfolio builder for developers. Create a professional portfolio website without writing any frontend code: fill in your profile, projects and skills, pick a template, and publish at your own username-based URL.

> 🚧 **Status:** Under active development.

## Tech Stack

**Frontend:** React, React Router, React Hook Form, Tailwind CSS, React Helmet Async

**Backend:** Node.js, Express, MongoDB, Mongoose, JWT, bcrypt

**Tools and services:** Git, Nodemailer, Cloudinary, Vercel, Render, MongoDB Atlas

## Project Structure

```
codefolio/
├── client/   # React frontend (dashboard and public portfolios)
└── server/   # Express REST API and MongoDB models
```
